# Квиз MEDELA «Какой Check-up подходит именно вам?»

Посадочная страница-квиз для трафика из Instagram, Facebook и Telegram. Цель — собрать заявку на Check-up.

Воронка: **выбор языка → стартовый экран → 5 вопросов → форма контактов → «Спасибо»**.

Квиз **не является медицинской диагностикой**: он не ставит диагноз, а только помогает подобрать формат обследования.

Стек: чистые HTML + CSS + JavaScript, без фреймворков, сборки и зависимостей.

```
medela-quiz/
├── index.html            разметка-каркас (без текстов интерфейса)
├── styles.css            стили (mobile-first)
├── app.js                логика квиза, валидация, отправка, аналитика
├── i18n.js               все тексты на русском и узбекском
├── config.js             данные клиники, цвета, логотип, endpoint, GTM ID
├── assets/               логотип, favicon
├── server/
│   ├── lib/lead.js       общая логика: проверка заявки и отправка в Telegram
│   ├── vercel/lead.js    функция для Vercel
│   └── netlify/functions/lead.js   функция для Netlify
├── api/lead.js           точка входа для Vercel (ссылается на server/vercel/lead.js)
└── netlify.toml          настройки Netlify (функции + /api/lead)
```

## Запуск локально

Нужен любой статический сервер (просто открыть `index.html` двойным кликом тоже можно, но `?lang=` и история браузера надёжнее работают через сервер):

```bash
git clone https://github.com/Rasim1706/medela-quiz.git
cd medela-quiz
python3 -m http.server 8080
# или: npx serve .
```

Откройте http://localhost:8080. Полезные ссылки для проверки:

- http://localhost:8080/?lang=ru — сразу русский, экран выбора языка пропускается
- http://localhost:8080/?lang=uz&utm_source=instagram&utm_campaign=checkup — узбекский + UTM-метки

Пока `leadEndpoint` в `config.js` пустой, заявка **не отправляется**, а выводится в консоль браузера (режим разработки), и пользователь видит экран «Спасибо».

Проверка аналитики: в консоли браузера выполните `console.log(window.dataLayer)`.

## Настройка

### Тексты

Все тексты находятся в `i18n.js` (объекты `ru` и `uz`). Меняйте только текст справа от двоеточия. Ключи вариантов ответов (`under30`, `heart`, `tashkent` и т.д.) — это машинные коды: они уходят в заявку и в аналитику, их лучше не трогать.

Узбекский текст написан латиницей с правильными символами: `oʻ`, `gʻ` (U+02BB) и `ʼ` (U+02BC). Копируйте их из существующих строк, не заменяйте на обычный апостроф.

Порядок вопросов и список вариантов задаются в начале `app.js` (массив `QUESTIONS`). Если добавляете вариант, добавьте и его текст в оба языка в `i18n.js`.

### Цвета

В `config.js` → `colors`. Каждый ключ становится CSS-переменной: `brand` → `--brand`, `brandLight` → `--brand-light` и т.д. Те же значения продублированы в начале `styles.css` как запасные.

| Ключ | Назначение |
| --- | --- |
| `brand` | кнопки, прогресс, выбранные варианты, фокус |
| `brandLight` | второстепенные акценты, градиент прогресса |
| `brandSoft` | заливка выбранного варианта, бейджи, подсказки |
| `brandText` | тёмный бирюзовый для мелкого текста и ссылок (контраст WCAG AA) |
| `accent` | коралловый, только hover главной кнопки |
| `bg`, `surface` | фон страницы и карточки |
| `text`, `textMuted`, `border` | текст и рамки |

Текст на главной кнопке — 19px bold: для белого текста на `#3398A7` это нужно, чтобы пройти WCAG AA (контраст 3,4:1 допустим только для крупного текста). Если сделаете кнопку мельче — затемните `brand`.

### Логотип

Положите файлы в `assets/`:

- `assets/logo.png` — основной логотип (https://medela.uz/wp-content/themes/medela/images/logo.png)
- `assets/logo-mob.png` — мобильная версия (https://medela.uz/wp-content/themes/medela/images/logo-mob.png), используется на экранах до 480px

> При сборке квиза сайт medela.uz был недоступен из окружения разработки, поэтому файлы логотипа **не скачаны**. Пока файлов нет, в шапке показывается текстовый логотип «MEDELA». Как только файлы появятся в `assets/`, логотип подхватится автоматически — ничего менять не нужно.

Другие пути или формат (например, SVG) задаются в `config.js` → `logo.src` / `logo.srcMobile`. Высота логотипа в шапке — 36px (`.logo__img` в `styles.css`).

### Данные клиники

`config.js` → `clinic`: телефон (`phoneDisplay` — как показывать, `phoneHref` — ссылка `tel:`), сайт для кнопки «Вернуться на главную», Telegram, Instagram, адрес, график.

### Политика конфиденциальности

`config.js` → `privacyUrl`. Если строка пустая, текст согласия показывается без ссылки. Если указать адрес, слова «обработку персональных данных» / «Shaxsiy maʼlumotlarimni qayta ishlashga» станут ссылкой (откроется в новой вкладке).

### Meta Pixel

`config.js` → `metaPixelId` (сейчас `928181753700398`). Пустая строка — пиксель не подключается. Какие события уходят в пиксель — в разделе «Аналитика».

### Google Tag Manager

`config.js` → `gtmId` (сейчас `GTM-T8TNNP82`). Пустая строка — GTM не подключается. Скрипт GTM подключается из `app.js` по стандартной схеме (`gtm.start` + `gtm.js`).

## Отправка заявок

### Формат заявки

`POST` на `leadEndpoint`, `Content-Type: application/json`:

```json
{
  "lang": "uz",
  "age": "40–49 лет",
  "lastCheckup": "Более года назад",
  "motivation": "Хочу проверить здоровье профилактически",
  "focusAreas": ["Сердце и сосуды", "Показатели крови"],
  "city": "Самарканд",
  "name": "Каримова Дилноза",
  "phone": "+998901234567",
  "callTime": "Утро (8:00–12:00)",
  "codes": {
    "age": "40_49", "lastCheckup": "over1y", "motivation": "prevention",
    "focusAreas": ["heart", "blood"], "city": "samarkand", "callTime": "morning"
  },
  "utm_source": "instagram", "utm_medium": "cpc", "utm_campaign": "checkup",
  "utm_content": "", "utm_term": "", "fbclid": "",
  "referrer": "https://l.instagram.com/",
  "submittedAt": "2026-09-28T11:27:44.922Z"
}
```

Ответы всегда передаются **человекочитаемыми строками на русском** (для менеджеров), независимо от языка прохождения. Машинные коды вариантов — в `codes`. Язык прохождения — в `lang`.

Любой ответ сервера с кодом 2xx считается успехом. При ошибке сети, таймауте (15 секунд, `requestTimeoutMs`) или ответе не 2xx пользователь видит спокойное сообщение «Не удалось отправить, попробуйте ещё раз», кнопку повтора и телефон клиники. Ответы при этом не теряются.

### Отправка в Telegram (serverless-функция)

В папке `server/` готова функция, которая принимает заявку, проверяет её и отправляет карточку в Telegram-чат менеджеров:

```
🩺 Новая заявка на Check-up

👤 Имя: Каримова Дилноза
📞 Телефон: +998 90 123 45 67
🕐 Удобное время: Утро (8:00–12:00)
🌐 Язык: UZ

🎂 Возраст: 40–49 лет
📅 Последнее обследование: Более года назад
💡 Мотивация: Хочу проверить здоровье профилактически
🔍 Проверить в первую очередь: Сердце и сосуды, Показатели крови
📍 Город: Самарканд

📊 UTM: source=instagram · campaign=checkup
🗓 Получено: 28.09.2026, 16:25 (Ташкент)
```

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите **токен**.
2. Добавьте бота в группу менеджеров и напишите в группе любое сообщение.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…}` — это **chat_id**.
4. В настройках проекта на Vercel / Netlify добавьте переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — id чата
   - `ALLOWED_ORIGIN` — *необязательно*, только если квиз и функция на разных доменах (например, `https://quiz.medela.uz`)
5. В `config.js` укажите `leadEndpoint: '/api/lead'` (или полный адрес функции, если она на другом домене).

**Токен бота и chat_id хранятся только в переменных окружения сервера.** Во фронтенде и в репозитории их быть не должно. В папке `server/` секретов нет — это только код.

Функция отбрасывает заявки с заполненным скрытым полем `website` (ловушка для ботов) и проверяет имя и телефон. При большом количестве спама стоит дополнительно включить защиту на уровне хостинга (rate limiting, Cloudflare).

## Деплой

Квиз — статический сайт: содержимое репозитория можно разместить на любом хостинге (nginx, S3, GitHub Pages, поддомен `quiz.medela.uz`). Функция отправки заявок работает на Vercel и Netlify.

### Vercel

1. Импортируйте репозиторий в Vercel.
2. **Root Directory** — оставьте корень репозитория, Framework Preset → **Other**, Build Command — пусто.
3. Добавьте переменные окружения `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Deploy. Функция будет доступна по адресу `/api/lead` (файл `api/lead.js`).

### Netlify

1. Импортируйте репозиторий в Netlify.
2. **Base directory** — оставьте пустым. Остальное берётся из `netlify.toml` (публикуется папка целиком, функции — из `server/netlify/functions`, адрес `/api/lead` перенаправляется на функцию).
3. Добавьте переменные окружения `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Deploy.

### Поддомен quiz.medela.uz

В DNS добавьте запись `CNAME quiz → <адрес проекта на Vercel/Netlify>` и подключите домен в настройках проекта. Если квиз лежит на другом хостинге, а функция на Vercel/Netlify — укажите полный адрес функции в `leadEndpoint` и домен квиза в `ALLOWED_ORIGIN`.

### Ссылки для рекламы

- Русскоязычная кампания: `https://quiz.medela.uz/?lang=ru&utm_source=instagram&utm_medium=cpc&utm_campaign=checkup_ru`
- Узбекоязычная кампания: `https://quiz.medela.uz/?lang=uz&utm_source=telegram&utm_medium=cpc&utm_campaign=checkup_uz`

Без `lang` пользователь сначала видит экран выбора языка. Meta добавляет `fbclid` автоматически, он уходит в заявку.

## Страница записи через Telegram-бота (`/zapis`)

Отдельная посадочная страница `zapis/` для рекламы, которая ведёт сразу в бота **@medelazapisbot**. После деплоя открывается по адресу `https://<ваш-домен>/zapis`.

- Бот задаётся в `config.js` → `clinic.telegramBot`, пиксель и GTM берутся из того же `config.js`.
- Тексты на русском и узбекском — в начале `zapis/zapis.js` (объект `TEXTS`). Язык: `?lang=ru` / `?lang=uz`, иначе — последний выбранный или язык браузера.
- Кнопка ведёт на `https://t.me/medelazapisbot?start=<язык>-<utm_source>-<utm_content>`, например `ru-instagram-c2_last_checkup_ru_4x5`. Бот получает этот параметр в команде `/start` и может записать, из какой рекламы пришёл человек.
- События: нажатие на кнопку бота → Meta Pixel **`Lead`** и `zapis_bot_click` в dataLayer; нажатие на телефон → `Contact` и `zapis_phone_click`. Перед переходом в Telegram страница ждёт 0,3 секунды, чтобы пиксель успел отправить событие.

Ссылка для рекламы: `https://<ваш-домен>/zapis?lang=ru&utm_source=instagram&utm_content=c1_quiz_ru_4x5`

## Аналитика (dataLayer и GTM)

Все события отправляются в `window.dataLayer`. Имён и телефонов там **нет**.

| Событие | Параметры | Когда |
| --- | --- | --- |
| `quiz_language_select` | `lang`, `source` (`screen` / `switch` / `url`) | выбор языка на первом экране, в шапке или через `?lang=` |
| `quiz_start` | `lang` | нажатие «Начать» |
| `quiz_step` | `step` (1–5), `answer_code` (для вопроса 4 — коды через запятую) | ответ на вопрос и переход дальше |
| `quiz_submit_click` | `lang` | нажатие «Отправить заявку» |
| `quiz_lead_submit` | `lang`, `city`, `age` (коды) | заявка успешно отправлена |
| `contact_click` | `channel` (`phone` / `telegram`) | нажатие на телефон или Telegram |

### Настройка в GTM

1. **Переменные** → Пользовательские → «Переменная уровня данных»: создайте `DLV - lang`, `DLV - step`, `DLV - answer_code`, `DLV - city`, `DLV - age` (имя переменной уровня данных — `lang`, `step` и т.д.).
2. **Триггеры** → «Пользовательское событие»:
   - `CE - quiz_lead_submit` — имя события `quiz_lead_submit`
   - `CE - quiz_start` — `quiz_start`
   - `CE - quiz_step` — `quiz_step`
   - при желании: `CE - quiz_all` — имя события `quiz_.*`, флажок «Использовать регулярные выражения».
3. **Meta Pixel** уже встроен в квиз (`config.js` → `metaPixelId`), **в GTM его добавлять не нужно**, иначе события задвоятся. Квиз сам отправляет в пиксель:

   | Событие пикселя | Когда |
   | --- | --- |
   | `PageView` | открытие страницы |
   | `QuizStart` (custom) | нажатие «Начать» |
   | `QuizStep` (custom, параметр `step` 1–5) | ответ на вопрос |
   | `SubmitClick` (custom) | нажатие «Отправить заявку» (даже если форма заполнена с ошибками) |
   | **`Lead`** | заявка успешно отправлена — используйте как конверсию в рекламе |
   | `Contact` (параметр `channel`: `phone` / `telegram`) | нажатие на телефон или Telegram |

   Ответы квиза (возраст, город, симптомы, что проверить) в Meta **не передаются**: это данные о здоровье, за них Meta ограничивает пиксель. Они остаются только в заявке и в dataLayer.

   Проверка: расширение Meta Pixel Helper или Events Manager → «Тестовые события».

4. **GA4**:
   - тег «Google Tag» с Measurement ID `G-XXXXXXX` на All Pages;
   - тег «Событие GA4» с названием `generate_lead` (рекомендуемое событие) и параметрами `lang`, `city`, `age` на триггер **CE - quiz_lead_submit**; отметьте это событие как ключевое (конверсию) в GA4;
   - тег «Событие GA4» с названием `{{Event}}` и параметрами `step`, `answer_code`, `lang` на триггер `CE - quiz_all` — для построения воронки по шагам (Исследования → Воронка).
5. Проверьте в режиме **Preview** (Tag Assistant): пройдите квиз и убедитесь, что теги срабатывают на нужных событиях. Затем **Submit / Publish**.

## Как устроен квиз

- Один вопрос на экран, переход с короткой анимацией (отключается при системной настройке «уменьшить движение»).
- Вопросы с одним вариантом — переход сразу по нажатию. Если вернуться к вопросу, на котором уже есть ответ, появляется кнопка «Далее».
- Вопрос 3: при выборе «Есть беспокоящие меня симптомы» показывается спокойная подсказка и кнопка «Далее» вместо автоперехода.
- Вопрос 4: множественный выбор; «Хочу комплексную проверку» взаимоисключает остальные варианты. «Далее» неактивна без выбора.
- Вопрос 5: если город не Ташкент — подсказка и кнопка «Далее».
- «Назад» (в карточке и кнопка «назад» браузера/телефона) и смена языка не теряют ответы.
- Состояние хранится в памяти. В `localStorage` (в try/catch) сохраняются только ответы на вопросы, без имени и телефона, на 72 часа (`storageTtlHours`); после успешной отправки они удаляются.
- Телефон: маска `+998 (__) ___-__-__`, префикс +998 подставлен и не стирается, вставка номера в любом формате (`+998 90 …`, `90…`, `998…`) распознаётся.
- Доступность: зоны нажатия от 48px, варианты — `role="radio"` / `role="checkbox"` с `aria-checked`, прогресс — `role="progressbar"`, ошибки связаны с полями через `aria-describedby`, при смене экрана фокус переходит на заголовок.
