# Учёт лидов MEDELA в Google Таблице

Все заявки из разных источников собираются в одну таблицу. Сразу видно, откуда пришёл человек, дошёл ли он до клиники и сколько стоит лид.

## Как это устроено

```
Квиз Check-up (Medela_leads)  ─┐
                               ├──►  Google Таблица  ◄── вручную: звонки, Direct, «пришёл сам»
Бот записи (MedelaStaffBot)  ──┘     (веб-приложение Apps Script)
```

Каждый бот отправляет заявку **в группу, как сейчас, и параллельно в таблицу**. Просто читать группу третьим ботом нельзя: Telegram не показывает ботам сообщения других ботов.

Таблица принимает:
- **JSON с полями**: так отправляет функция квиза `server/lib/lead.js`;
- **просто текст сообщения из группы**: `{"text": "..."}`. Таблица сама разберёт оба формата: «КВИЗ CHECK-UP» и «Заявка #N» от MedelaStaffBot. Владельцу бота нужно добавить одну строку кода.

## Листы

**Лиды** — одна строка на заявку:

| Колонка | Откуда |
|---|---|
| №, Дата и время | автоматически |
| Канал | Квиз Check-up / Telegram-бот / Сайт /zapis / Звонок / Instagram Direct / … |
| Площадка | Instagram / Facebook / Meta / Telegram / Google / Органика — определяется по UTM и метке бота |
| Кампания / объявление | ID кампании и объявления из Meta |
| Имя, Телефон, Услуга, Врач, Язык, Город, Когда удобно | из заявки |
| **Статус** | Новый → Не дозвонились → В работе → Записан → Пришёл / Отказ / Спам. Заполняет администратор, строка окрашивается |
| Дата визита, Сумма, Ответственный, Комментарий | заполняет администратор |
| Повтор | «Повтор», если этот номер уже был за последние 30 дней |
| Детали, Метка / UTM, Telegram ID, ID в системе | для разбора: возраст, мотивация, UTM, номер заявки в кабинете |

**Сводка** за выбранный период (жёлтые ячейки можно менять):
- по площадкам: лиды, без повторов, записан, пришёл, конверсия в визит, выручка. Если вписать **расход на рекламу**, посчитается **цена лида и цена визита**;
- по каналам и по статусам;
- лиды по дням за последние 14 дней.

**Справочники** — списки каналов, площадок, статусов и ответственных. Сюда впишите имена администраторов.

## Установка (10 минут, один раз)

1. Создайте пустую Google Таблицу, например «MEDELA — лиды».
2. **Расширения → Apps Script.** Удалите всё из `Code.gs` и вставьте содержимое файла [`Code.gs`](Code.gs). Сохраните.
3. Вверху выберите функцию **`setup`** → **Выполнить** → разрешите доступ к таблице. Листы, колонки, списки и сводка создадутся сами.
4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - Выполнять от имени: **меня**
   - У кого есть доступ: **все**
   - **Развернуть**.
5. Вернитесь в таблицу и обновите страницу. Появится меню **MEDELA → Показать ссылку для ботов**. Скопируйте ссылку вида
   `https://script.google.com/macros/s/…/exec?key=…`
   Ключ в конце защищает таблицу от чужих запросов, поэтому ссылку никому не публикуйте.
6. Для проверки: **MEDELA → Добавить тестовые заявки**. Появятся две строки (квиз и бот). Удалите их после проверки.

## Подключение ботов

### Квиз Check-up (функция `server/lib/lead.js` из этого репозитория)

В Vercel → проект → **Settings → Environment Variables** добавьте `SHEETS_WEBHOOK_URL` со ссылкой из шага 5 и сделайте **Redeploy**. После этого каждая заявка квиза уходит и в группу, и в таблицу. Если Telegram временно недоступен, заявка всё равно попадёт в таблицу.

### MedelaStaffBot и любой другой бот

Там, где бот отправляет заявку в группу, добавьте отправку того же текста в таблицу.

Node.js:
```js
// после отправки сообщения в группу; text — тот же текст заявки
fetch(process.env.SHEETS_WEBHOOK_URL, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text })
}).catch((e) => console.error('sheets', e));
```

Python:
```python
requests.post(os.environ["SHEETS_WEBHOOK_URL"], json={"text": text}, timeout=10)
```

Если удобнее отправлять поля, а не текст: `{"channel":"Telegram-бот","name":"…","phone":"…","service":"…","doctor":"…","lang":"ru","utm_source":"fb","campaign":"1202…","telegramId":"…","externalId":"#2"}`.

### Звонки, Instagram Direct, «пришёл сам»

Администратор добавляет строку вручную. Канал и площадку выбирает из списков.

## Как пользоваться

- Администратор отвечает на заявку и меняет **Статус**, а после визита ставит «Пришёл», дату визита и сумму.
- Раз в неделю: впишите расход на рекламу по площадкам в **Сводке** и сравните цену визита по Instagram, Facebook и Telegram.
- Фильтр в шапке листа «Лиды» показывает только новые заявки, нужную площадку или конкретного администратора.
