# Учёт лидов MEDELA: Google Таблица + бот для пересылки заявок

Все заявки из группы попадают в одну Google Таблицу. Администратор ставит статус **Квал / Не квал / Недозвон**, а лист «Статистика» сам считает лиды по площадкам, каналам и причинам отказа.

Сервер не нужен, код ботов MedelaStaffBot и Medela_leads трогать не нужно, всё бесплатно.

## Как это работает

```
Группа с заявками ──(администратор пересылает)──► ваш бот-учётчик ──► Google Таблица «Лиды»
```

- Администратор выделяет заявки в группе (одну или сразу несколько) и **пересылает** их боту.
- Раз в минуту скрипт таблицы забирает новые сообщения бота, разбирает текст и добавляет строки. Бот отвечает: «✅ Добавлено (строка 15): Имя · Канал».
- Разбирается **любой формат** заявки: «КВИЗ CHECK-UP», «Новая заявка с квиза 🔥», «Заявка #N» (MedelaStaffBot) и даже свободный текст. Телефон ищется в любом месте, поля «Метка: значение» раскладываются по колонкам, всё остальное («Беспокоит», «Детали», «Аргумент для звонка», 🔥, хэштеги) попадает в «Детали заявки». Поля: имя, телефон, услуга, врач, язык, город, удобное время, площадка (Instagram / Facebook / …), ID кампании, Telegram ID и номер заявки.
- Дата в таблице — это время исходного сообщения в группе, а не время пересылки.
- Если переслать заявку повторно, бот ответит «⚠️ Уже в таблице», и дубля не будет.
- Если этот номер телефона уже был за последние 30 дней, в колонке «Повтор» появится отметка.

> Почему нельзя просто добавить бота в группу: Telegram не показывает ботам сообщения других ботов, поэтому заявки нужно переслать.

## Таблица

**Лиды:** №, **дата**, **время** (отдельно), имя, телефон, **воронка**, площадка, услуга / жалоба, **Прозвон 1 / 2 / 3**, **статус** (строка целиком окрашивается: Квал — зелёная, Не квал — красная, Недозвон — синяя), причина «не квал», **дата и время визита**, **оператор**, комментарий, повтор. Дальше детали: врач, язык, город, удобное время, кампания, UTM, Telegram ID, ID заявки.

- **Воронка** определяется по заголовку заявки:
  - «КВИЗ CHECK-UP» → **Квиз Check-up**;
  - «Новая заявка с квиза» → **Квиз по самочувствию**;
  - «Заявка #N» → **Бот записи**;
  - новый, незнакомый формат получает название из своего заголовка (например, «Заявка с лендинга УЗИ»).

  Значение можно поменять вручную из списка.
- **Прозвон 1–3:** оператор выбирает результат звонка («✅ Дозвонился», «📵 Не взял трубку», «🔕 Выключен», «⏰ Просил перезвонить», «❌ Неверный номер»). В ячейку автоматически добавляется примечание со временем звонка. Если все три прозвона без ответа, статус сам становится **«Недозвон»**.
- **Дата визита:** день, на который пациент записан. При двойном клике открывается календарь. Визит **сегодня** подсвечивается оранжевым, **завтра** — светло-оранжевым. Бот по команде `/stats` показывает визиты на сегодня.
- **Оператор:** имена операторов впишите на листе «Списки» в колонку E (жёлтые ячейки). Они появятся в выпадающем списке.

**Статистика** (бывший лист «Статистика») — дашборд за период (даты в жёлтых ячейках, по умолчанию текущий месяц):
- карточки с крупными цифрами: всего лидов, ✅ квал, ❌ не квал, 📵 недозвон, ⏳ не обработано, 📅 записаны на визит (с процентами);
- строка «Сегодня визитов · завтра»;
- по воронкам и по операторам: лиды, квал, не квал, недозвон, % квал и полоска доли;
- реклама по площадкам: впишите расход в жёлтые ячейки, и посчитается цена лида и цена квал-лида (вписанные суммы сохраняются при обновлении);
- причины «не квал» с полосками;
- записи на визит на ближайшие 7 дней;
- графики «Лиды по дням» и «Квал-лиды по дням» за 14 дней.

**Списки** — значения для выпадающих меню: воронки, площадки, статусы, причины, операторы, результаты прозвона.

## Оформление

Все строки одинаковой высоты, длинный текст не растягивает строку (полный текст виден в строке формул при клике). Один шрифт, короткие поля по центру, тонкие светлые рамки вместо сетки. Если вид «поехал» (например, после ручного копирования), выберите **MEDELA → Оформить таблицу**: данные при этом не меняются.

## Обновление со старой версии

Вставьте новый `Code.gs` в Apps Script → 💾 → в таблице **MEDELA → 1. Настроить / обновить таблицу**. Уже внесённые заявки перенесутся в новые колонки: «Дата и время» разделится на дату и время, «Канал» станет «Воронкой», «Ответственный» — «Оператором». Бота подключать заново не нужно.

## Установка (10 минут, один раз)

### 1. Таблица
1. Создайте пустую Google Таблицу: sheets.new.
2. **Расширения → Apps Script.** Удалите всё в `Code.gs`, вставьте содержимое файла [`Code.gs`](Code.gs) и сохраните (💾).
3. Вверху выберите функцию **`setup`** → **Выполнить** → **Проверить разрешения** → выберите свой аккаунт → «Дополнительные настройки» → «Перейти в проект» → **Разрешить**.
4. Вернитесь в таблицу и обновите страницу. Появится меню **MEDELA**.

### 2. Бот-учётчик
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя, например `MEDELA учёт лидов`, и username, например `medela_leads_table_bot`. Скопируйте **токен**.
2. В таблице: **MEDELA → 2. Подключить Telegram-бота** → вставьте токен → разрешите доступ.
3. Откройте своего бота в Telegram и нажмите **Старт**. Первый, кто это сделает, становится администратором бота.
4. Перешлите боту любую заявку из группы. Через минуту она появится в таблице.

### Доступ для коллег
Коллега пишет боту что угодно, и бот показывает ему его ID. Вы отправляете боту `/add ID`, и коллега тоже может пересылать заявки.

### Команды бота
- `/stats` — сколько лидов сегодня: квал, не квал, недозвон, не обработано.
- `/add ID` — дать доступ коллеге.

## Дополнительно: заявки без пересылки

Если когда-нибудь появится доступ к коду ботов, их можно подключить напрямую, без пересылки:
1. **Развернуть → Новое развёртывание → Веб-приложение** (выполнять от: «Я», доступ: «Все»).
2. **MEDELA → Ссылка для приёма заявок** — скопируйте ссылку с `?key=…`.
3. Бот после отправки в группу делает POST на эту ссылку с телом `{"text": "текст заявки"}`. Квиз из этого репозитория делает это сам, если задать в Vercel переменную `SHEETS_WEBHOOK_URL`.

Повторная заявка (тот же текст или тот же номер «Заявка #N») не задвоится, даже если её и переслали, и прислали напрямую.

## Ручной вариант без бота

[`MEDELA-лиды.xlsx`](MEDELA-лиды.xlsx) — та же таблица со статусами Квал / Не квал / Недозвон для ручного заполнения: загрузите её в Google Drive и откройте как Google Таблицу.
